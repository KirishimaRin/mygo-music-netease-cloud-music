# 网易云音乐 · MyGo Music 插件

[![Version](https://img.shields.io/badge/version-0.1.4-blue.svg)](plugin.json)
[![Min Host Version](https://img.shields.io/badge/MyGo%20Music-%E2%89%A5%200.1.20-brightgreen.svg)](https://github.com/egoist/mygo-music)
[![Language](https://img.shields.io/badge/language-JavaScript%20(ESM)-yellow.svg)](index.js)

为 [MyGo Music](https://github.com/egoist/mygo-music) 打造的全功能网易云音乐扩展插件。通过手机网易云音乐 App 扫码登录，即可在 MyGo Music 中无缝畅听每日推荐、私人 FM、播客、歌单及官方排行榜，享受逐字歌词、评论互动与高品质音频体验。

插件由 MyGo Music 宿主直接沙箱加载执行，**无需配置 Node.js 环境、无外部二进制依赖（免 FFmpeg）、无需启动额外的本地 API 代理服务**，轻量即装即用。

---

## 核心特性

### 认证与账号
- **扫码登录**：支持通过手机网易云音乐 App 直接扫码登录，自动轮询授权状态。
- **凭据持久化**：登录凭据存储在 MyGo Music 宿主提供的本地隔离存储中，支持重启后自动恢复会话；退出登录时彻底清除本地凭据。
- **多端同步**：登录后自动同步云端歌单、红心歌曲、订阅播客与关注歌手。

### 音频播放与音质控制
- **流媒体解析**：支持 MP3、FLAC、OGG 等格式直接拉取，包含码率（bitRate）、文件大小（size）、音轨增益（gain/ReplayGain）与峰值（peak）信息。
- **宿主音频解码**：网易云返回 AAC 或 M4A 时直接交给 MyGo Music 解码。分片 MP4 和 MP4 封装的 FLAC 需要 MyGo Music 0.1.21 或更高版本。
- **试听拦截**：智能识别 VIP 试听限制（`freeTrialInfo`），对不可用音源明确提示，避免将试听片段误作为完整曲目播放。
- **音质偏好配置**：
  - 支持在插件设置中指定偏好档位：`standard`（标准）、`higher`（较高）、`exhigh`（极高）、`lossless`（无损/FLAC）、`hires`（Hi-Res）。
  - 无损或 Hi-Res 不可用时依次降到极高、标准，并无缝映射到 MyGo Music 宿主的 `standard` / `high` / `lossless` 缓存体系中。

### 发现与个性化音乐
- **为你推荐（首页）**：
  - 聚合精选歌单推荐与官方四大榜单（飙升榜、新歌榜、原创榜、热歌榜）。
  - 登录后自动加入「今日为你推荐」个性化分区，并与全局热门推荐智能去重。
  - 从「分类歌单」按曲风、语种等浏览歌单。
- **每日推荐**：专属每日歌曲推荐列表，直观展示当日推荐曲目数量。
- **私人 FM**：支持原生切换器，内置四档模式自由切换：
  - **推荐**：经典私人推荐算法。
  - **熟悉**：偏好常听曲目。
  - **探索**：发现风格相似的新音乐。
  - **心动模式**：以红心歌单中的歌曲作为随机种子，持续智能接续推荐。
- **播客频道**：
  - 包含精选播客推荐、热门播客排行榜及个人已订阅播客分组。
  - 支持按类别发现播客。点击节目详情中的主播名字，可以查看主播资料和已发布的播客。
  - 支持节目搜索、节目详情查看、单集播放与播客评论。

### 互动、歌单与歌词
- **完整歌单管理**：
  - 新建歌单（默认私密）、重命名歌单、删除歌单、收藏/取消收藏外部歌单。
  - 歌单歌曲批量添加、批量移除以及拖拽重新排序（自动映射显示索引与服务端真实序列，遇 512 错误协议级重试）。
- **互动能力**：
  - 歌曲点红心收藏 / 取消收藏。
  - 专辑收藏 / 取消收藏，从侧栏「收藏的专辑」查看。
  - 播客单集点赞、播客节目一键订阅。
  - 歌手主页关注 / 取消关注。
  - 浏览和点赞热门评论，在歌曲或播客单集的评论页发表评论。
- **我的主页**：从账号菜单打开，查看自己的歌单、关注的歌手和本周听歌排行。
- **逐字歌词与翻译**：
  - 优先解析网易云 `yrc` 高精度逐字时间戳歌词及中文翻译。
  - 缺少逐字数据时，自动平滑回退至传统 `lrc` 逐行歌词与翻译。
- **播放历史记录**：
  - 登录后从侧栏「最近播放」查看同一账号最近 50 条歌曲播放记录。
  - 支持可选将歌曲播放开始事件同步回网易云云端。

### 性能与网络优化
- **封面按显示尺寸加载**：网易云图片 URL 带 `param={size}y{size}`，MyGo Music 按每个视图的实际像素填入尺寸，列表里不再下载上千像素的原图。旧版固定尺寸方案实测首页 16 张封面从约 2.92 MB 降到 1.06 MB。
- **短时请求复用**：首页与每日推荐/排行榜之间的公共数据实现 60 秒内存防抖复用，按会话严格隔离。
- **大歌单并发分页**：百首以上大型歌单采用首包轻量元数据 + 后续分批并发请求详情策略，实测 638 首歌单比首包拉取 500 首更快。
- **网络容错**：首页任一分区失败不影响其他分区；超时与异常响应分别提示；大批量歌曲详情使用更长的超时。

## 安装方法

### 运行要求
- **宿主版本**：[MyGo Music v0.1.20](https://github.com/egoist/mygo-music/releases) 或更高版本。更早的宿主不会替换封面 URL 里的 `{size}`，封面无法加载。
- **平台支持**：Windows / macOS / Linux（由 MyGo Music 宿主保证跨平台支持）。

### 安装步骤

1. 打开 **MyGo Music**。
2. 进入 **设置 (Settings) → 插件 (Plugins) → 添加插件 (+)**。
3. 选择以下任一方式进行安装：
   - **从 GitHub 安装（推荐）**：粘贴本插件的 GitHub 仓库地址。
   - **从 Zip 文件安装**：选择对应版本的安装包，例如 `netease-cloud-music-0.1.4.zip`。
   - **从文件夹安装（开发调试）**：选中包含 `plugin.json` 的项目根目录。
4. 安装完成后，在插件列表中找到 **网易云音乐 (NetEase Cloud Music)**，点击 **登录**，使用手机网易云音乐 App 扫码并确认即可。

## 插件配置项

在 MyGo Music 的插件设置中，可按需配置以下选项：

| 配置项 (Key) | 选项名称 | 说明 | 可填值 | 默认值 |
| :--- | :--- | :--- | :--- | :--- |
| `quality` | 网易云音质偏好 | 向网易云请求音源时的首选音质档位。实际返回根据账号 VIP 权限由网易云协商，插件会自动降级适配。 | `standard` / `higher` / `exhigh` / `lossless` / `hires` | 留空（跟随 MyGo Music 宿主设置） |
| `syncHistory` | 同步播放记录 | 是否将本机播放开始事件同步至网易云历史记录中。 | 填 `on` 开启，留空关闭 | 留空（关闭） |

## 权限与安全说明

本插件遵循最小权限原则：
1. **网络白名单**（声明于 `plugin.json`）：
   - `interfacepc.music.163.com`：网易云桌面端加密 EAPI 接口通信（登录、歌单、推荐、音源解析、评论等）。
   - `music.163.com`：网易云网页端接口（用于歌手关注操作）。
   - `clientlog.music.163.com`：播放记录同步接口（仅在开启 `syncHistory` 时请求）。
2. **凭据安全**：
   - 登录凭据（`MUSIC_U` 及 `__csrf`）仅存储于本地宿主提供的沙箱存储中，不在任何第三方中转。
   - 音频文件均由 MyGo Music 宿主直接连接网易云官方 CDN（`*.music.126.net`）下载，CDN 请求不携带任何用户认证凭据。
   - 用户登出时会立即调用存储清理，本地不留存任何残留凭据。
